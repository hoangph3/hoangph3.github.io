Train Various Models on MNIST using kubeflow and seldon-core#

  1. Install kubeflow training-operator
$ kubectl apply -k "github.com/kubeflow/training-operator/manifests/overlays/standalone?ref=v1.5.0"
  1. Build training and serving components
$ python3 build_component.py
  1. Create a persistent volume to save model file
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: "nfs-1"
  namespace: seldon-model
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 4Gi

$ kubectl apply -f pvc.yml
persistentvolumeclaim/nfs-1 created
  1. Training tensorflow mnist model by the manifest file:
